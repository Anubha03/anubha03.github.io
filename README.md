# Anubha Vyasamudri — personal portfolio

Live website: https://anubha03.github.io

A static portfolio built with HTML and CSS. GitHub Pages serves the root of the `main` branch.

## Edit the website

- `index.html`: biography, projects, internships, education, and links.
- `style.css`: layout, colors, typography, and responsive styles.
- `assets/`: portrait, resume, and project reports.

Commit and push changes to `main` to publish updates automatically.

For a local preview, run `python3 -m http.server 4173` and open http://localhost:4173.
