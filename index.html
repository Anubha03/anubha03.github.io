LLM calibration & efficient inference

Uncertainty-Aware Inference

A Columbia group project, mentored by IBM Research, studying how model compression affects the reliability of LLM confidence scores. We compared four quantization methods across 15 model configurations and simulated routing uncertain questions to a higher-precision model to explore cost and quality tradeoffs.

Tool-using agents & security

Bounded Security Agent

An agent that investigates Python security alerts from Bandit using read-only tools and a limited investigation budget. It reviews the surrounding code and produces classifications with line-cited explanations, structured reports, and execution traces so its decisions can be inspected.

Computer vision & 3D scenes

Multi-view 3D Gaussian Segmentation

A team project for selecting and editing objects in 3D Gaussian scenes using text prompts. GroundingDINO and SAM2 generate masks across 18 camera views, while depth-aware voting and consistency filters map them into 3D, supporting object recoloring, removal, and instruction-based edits without retraining the scene.

Explainable computer vision

Plant Disease Detection

An interactive application that classifies leaf images across 38 plant disease classes using EfficientNetB3. The Streamlit interface pairs predictions with Grad-CAM and LIME visualizations to explain which image regions influenced the result, with optional language-model backends for treatment suggestions.
