LLM calibration & efficient inference

Uncertainty-Aware Inference

In this Columbia group project, mentored by IBM Research, we studied how quantization affects the confidence of language models. We compared four quantization methods across 15 model configurations.

We compared confidence with actual correctness using ECE, MCE, and Brier scores, and explored routing uncertain requests from quantized models to FP16 models. The routing results are simulations, giving us a way to examine cost and quality tradeoffs before deployment.

Multi-agent systems & retrieval

PawAI

PawAI is a dog-care assistant with separate agents for health, nutrition, and behavior. A router selects the relevant agents, and their answers are combined into one response based on the dog’s profile.

The system uses a quantized Llama model, FAISS retrieval over veterinary sources, a Flask backend, and a Streamlit chat interface. Nutrition calculations run in Python, while the agents use the dog’s profile and retrieved context to shape their responses.

Knowledge graphs & AI applications

FounderSignal

FounderSignal is a hackathon project for helping early-stage founders explore the AI startup ecosystem. It maps a startup into a knowledge graph and adds related companies and news through web discovery.

The dashboard lets users explore connections and ask questions about the startup. The backend uses Jac graph walkers and language models to build answers with supporting evidence and reasoning paths.

Conversational AI & evaluation

Expression AI

Expression AI explores ways to help a conversational assistant respond to frustration. It uses emotion signals to adapt prompts and generate responses intended to de-escalate a conversation.

The project connects model inference with a serving layer and A/B evaluation of conversational behavior. I designed conversation-level train/test splits across 50K conversations and 340K turns, keeping turns from the same conversation together to avoid leakage.

Tool-using agents & security

Bounded Security Agent

This agent reviews security alerts from Bandit, a static analysis tool for Python. It reads the surrounding code, investigates each alert with read-only tools, and gives a classification with references to the relevant lines.

The course project puts explicit limits on the investigation budget and records both a structured report and an execution trace. That makes it possible to inspect how the agent reached its answer, rather than seeing only the final label.

Computer vision & 3D scenes

Multi-view 3D Gaussian Segmentation

This team project identifies objects in a 3D Gaussian scene using a text prompt. It combines GroundingDINO and SAM2 masks from 18 camera views, then maps those 2D masks into the 3D scene.

Depth-aware voting, visibility normalization, and consistency filters help keep the selection from spilling into the background. Once selected, an object can be recolored, removed, or edited through a natural-language instruction—all without retraining the scene.

Explainable computer vision

Plant Disease Detection

This project classifies leaf images across 38 plant disease classes using EfficientNetB3. Grad-CAM and LIME visualizations show which parts of the image contributed to the prediction.

The Streamlit interface brings image upload, predictions, and visual explanations together. Optional cloud and local language-model backends add treatment suggestions, extending the project from a classifier into an interactive application.

A database-backed inventory application built for my databases course at Columbia. Employees can manage products, update stock, search inventory, and review the history of stock changes.

It uses Flask, PostgreSQL, SQLAlchemy, and server-rendered HTML. Stock changes record the employee, time, and reason, with login sessions, form validation, and parameterized SQL queries supporting the application.
